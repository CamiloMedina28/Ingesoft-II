En la carpeta de laboratorio se encuentra la actividad realizada en clase, con esta actividad, la idea es replicarlo en alguna de estas siguientes APIS, ustedes escogen, pueden combinar el API según el alcance ( usar una para el crud básico y otra para JWT por ejemplo) :


APIs Públicas y Gratuitas

 Entretenimiento / Cultura Pop
1. PokéAPI — Pokémon
https://pokeapi.co/api/v2/pokemon

GET /pokemon → lista todos
GET /pokemon/pikachu → info de uno
GET /pokemon/25 → por número
GET /ability/overgrow → habilidades
Sin registro, sin token


2. The Simpsons Quotes — Frases
https://thesimpsonsquoteapi.glitch.me/quotes

GET /quotes → frase aleatoria
GET /quotes?count=5 → 5 frases
Sin registro, sin token
Responde con personaje, imagen y frase


3. Rick and Morty
https://rickandmortyapi.com/api

GET /character → todos los personajes
GET /character/1 → Rick Sanchez
GET /episode → todos los episodios
GET /location → todas las ubicaciones
Sin registro, sin token


4. Studio Ghibli
https://ghibliapi.vercel.app/films

GET /films → todas las películas
GET /films/:id → película específica
GET /people → personajes
GET /species → especies
Sin registro, sin token


5. Breaking Bad Quotes
https://api.breakingbadquotes.xyz/v1/quotes

GET /quotes → frase aleatoria
GET /quotes/5 → 5 frases
Sin registro, sin token


6. The Lord of the Rings
https://the-one-api.dev/v2

GET /movie → todas las películas
GET /quote → frases aleatorias
GET /character → personajes
Requiere registro gratuito para token
Practicar Authorization Bearer


 Ciencia y Espacio
7. NASA — Astronomy Picture of the Day
https://api.nasa.gov/planetary/apod?api_key=DEMO_KEY

GET /apod → foto astronómica del día
GET /apod?date=2024-01-01 → foto de fecha específica
Usar DEMO_KEY como API Key (limitado) o registrarse gratis
Practicar query params y API Key


8. SpaceX
https://api.spacexdata.com/v4

GET /launches → todos los lanzamientos
GET /launches/latest → último lanzamiento
GET /launches/upcoming → próximos lanzamientos
GET /rockets → cohetes
Sin registro, sin token


9. Open Notify — ISS en tiempo real
http://api.open-notify.org

GET /iss-now.json → posición actual de la ISS
GET /astros.json → astronautas en el espacio ahora mismo
Sin registro, sin token
Datos cambian en tiempo real

11. Open Meteo — Clima gratis
https://api.open-meteo.com/v1/forecast

Clima actual de cualquier ciudad por coordenadas
Sin registro, sin token
Practicar query params múltiples

GET /advice/42 → consejo por ID

1. Elegir UNA API de la lista

2. En Postman crear mínimo 5 requests:
   - GET todos los recursos
   - GET uno por ID o filtro
   - Si tiene POST → crear uno
   - Usar query params en al menos una request
   - Escribir mínimo 2 tests automáticos

3. Exportar la colección como .json

4. Documento con capturas y responder:
   → ¿Qué API elegiste y por qué?
   → ¿Qué datos devuelve?
   → ¿Usa token o no? ¿Qué tipo?
   → ¿Qué código de estado recibiste en cada request?
   → ¿Qué aprendiste diferente a JSONPlaceholder?

Todo esto disponible en resumen en markdown en su repositorio GitHub para revisar

Finalmente con GraphQL con Postman

API a usar: https://countries.trevorblades.com/graphql

Requisitos mínimos:
1. Crear una colección en Postman llamada "Tarea GraphQL - [Nombre]"
2. Mínimo 5 requests con queries diferentes
3. Al menos una query anidada (datos relacionados)
4. Al menos una query con filtro por argumento
5. Mínimo 2 tests automáticos por request

Entregables:
- Colección exportada como .json
- Captura de pantalla de cada request con su respuesta
- Documento respondiendo:
   * ¿Qué diferencia encontraste vs REST?
   * ¿Cuántos requests REST necesitarías para
     reemplazar tu query más compleja?
   * ¿En qué proyecto real usarías GraphQL?
